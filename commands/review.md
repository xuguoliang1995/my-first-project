# /review

派发 `agents/code-reviewer.md` 子智能体，或按 `skills/requesting-code-review/SKILL.md` 自查。

评审顺序（不可颠倒）：

1. 对照 `proposal.md` 的验收点：它做的是需求要的吗？
2. 正确性：边界、错误、并发、空值
3. 安全：输入校验、鉴权、密钥、注入
4. 范围：有没有改不该改的文件
5. 最后才看可读性

输出按 P0/P1/P2/P3 分组，每条含**位置 / 问题 / 影响 / 建议**，并给出明确结论：
通过 / 有条件通过（列出必修项）/ 打回。

不把个人偏好当缺陷；不要求改动范围外的内容（记录为后续变更）。
